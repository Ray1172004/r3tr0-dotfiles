# Export review / Before installing

This is a curated export from the original archive. It excludes backup files, symlinks, bundled third-party Rofi templates, private assets, and potential secrets.

**Important:** Replace `/home/YOUR_USER/` with your actual home path where required (Hyprlock and Hyprpaper paths may not expand shell variables). Wallpaper images are not included, so configure image paths before starting. Verify that your installed Hyprland version supports the Lua syntax used here.

The original files were copied for review; the export has NOT been tested on a clean system. Avoid replacing all current dotfiles without backups.

Rofi themes and other authored/third-party materials may require attribution. Review third-party licenses before redistributing.
